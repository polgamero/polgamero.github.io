ARGENTINIA 23.21.3 — EMOJIS MULTIPLAYER

Ruta canónica:
  argentinia/assets/images/emotes/

Slots disponibles:
  emote_001 ... emote_012

Podés subir para cada slot UNO de estos formatos:
  emote_001.webp   (recomendado si es animado)
  emote_001.gif    (soportado)
  emote_001.png    (PNG estático o APNG animado)

El cliente intenta en ese orden: WEBP -> GIF -> PNG. Si ningún asset existe, muestra
el emoji Unicode de fallback. No hace falta cambiar código para reemplazar un PNG por GIF.

Recomendación visual: 256x256 px, fondo transparente, sujeto grande/centrado.
Para animados: ideal < 1 MiB por archivo y loops cortos (1-2 s). El envío además recibe
una animación CSS de entrada; si el usuario desactiva animaciones/reduced-motion, se muestra
sin movimiento.
