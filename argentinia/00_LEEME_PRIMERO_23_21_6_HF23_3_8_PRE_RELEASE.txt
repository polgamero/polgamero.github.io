P0 TOURNAMENT FIX
- Ordinary Tournament screen loads are now read-only: resolveInterrupted=false.
- Opening Tournament in a second tab can no longer eliminate a live match as a side effect of reading the fixture.
- A tab-scoped active-match marker is written only after economyBeginTournamentMatch succeeds.
- At terminal game state, a tab-scoped pending settlement is persisted BEFORE economySettleTournamentMatch.
- On same-tab reload, pending settlement is retried first. Only when no pending terminal result exists may that same reloaded tab resolve its own active match as interrupted.
- A fresh/second tab never auto-resolves interruption.
- If the server still reports activeMatch, the fixture blocks Play/Abandon and shows an explicit recovery panel.
- If a pending result exists, the only CTA is Reintentar guardado.
- If there is no pending result, Resolver partida interrumpida is manual and requires confirmation.
