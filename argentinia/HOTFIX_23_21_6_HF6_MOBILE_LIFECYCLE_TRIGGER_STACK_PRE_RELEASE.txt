HF6 DELTAS
1. Solo mobile lifecycle safe suspend
   - visibility hidden freezes Solo effective-play elapsed time, stops recovery heartbeat and invalidates the Tano priority timer.
   - stable gameplay gets an immediate checkpoint; if a target/payment/order modal is transiently active, the previous stable gameplay snapshot is preserved and only lifecycle timing metadata is frozen.
   - hidden < 2 minutes: soft resume, restart heartbeat, short Telemetry grace, re-arm exactly one Tano callback if rival still owns priority.
   - hidden >= 2 minutes: block stale table interaction, show “Reanudando partida suspendida…”, controlled reload, then use the existing active-game recovery modal. Controlled reload bypasses the normal beforeunload confirmation.
   - background time is excluded from effective match duration.

2. Tano single-owner scheduler
   - one timer owner + epoch fencing replaces unsafe anonymous stale callbacks for Solo priority scheduling.
   - scheduler refuses to run while page/lifecycle is suspended, trigger order/SBA is pending, or counter-tax / scry-surveil / proliferate interactive resolution is paused.

3. Trigger-order / priority race fix
   - attack and block declaration trigger batches are now atomic with their ordering step.
   - local attack: all simultaneous attack triggers finish human ordering and enter the Stack BEFORE priority passes to El Tano.
   - local blockers: all declaration triggers finish ordering BEFORE the new active-player priority window opens.
   - bot attack/block declarations obey the same ordering barrier.
   - fixes the reproduced incident where two “Espíritu del Monte — ataque” triggers were placed after priority had already moved to rival, consuming the one-shot Tano callback while the trigger-order modal was still pending.

4. Telemetry watchdog hardening
   - BOT_PRIORITY_STALL pauses while hidden/suspended and for a short soft-resume grace window.
   - BOT_PRIORITY_STALL now detects stalled rival priority with a NON-empty Stack too; the production incident had Stack depth 2 and was previously invisible to the automatic watchdog.
   - Telemetry remains observational only; it never mutates gameplay to repair a stall.
