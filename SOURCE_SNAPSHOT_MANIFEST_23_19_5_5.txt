TRANSACTION_BOUNDARY_NOTE:
- Admin single grants commit balance/inventory + playerStats + adminAction + economyEvent in one Firestore transaction.
- Admin Solo reward repair commits reward + balance + stats + adminAction + economyEvent in one Firestore transaction.
- Solo abandon commits points penalty + terminal playerGameReceipt + negative gameRewardReceipt + playerStats + immutable economyEvent in the canonical operation transaction. Legacy 23.19.5.4 operation-ledger replays run evidence-only backfill and never mutate points twice.
- Natural match settlement now commits missing playerGameReceipt + games/wins/losses/duration playerStats evidence server-side with the reward transaction; legacy 23.19.5.4 operation replays run an evidence-only idempotent backfill.
- Legacy server-authoritative non-match economy operations retain their pre-schema-6 canonical transaction, then run a second idempotent server transaction for playerStats + economyEvent. Replaying the same operationId also retries this audit/stat side effect, so an interrupted post-commit audit can be recovered without double counting.
